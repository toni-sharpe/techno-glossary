# Contributing to Techno Glossary

Thank you for your interest in contributing to the Techno Glossary! This project welcomes contributions from everyone.

## How to Contribute

### Adding or Updating Glossary Entries

1. Fork the repository
2. Create a new branch for your changes
3. Edit the `index.html` file to add or update entries
4. Test your changes locally by opening `index.html` in a browser
5. Commit your changes with a clear message
6. Push to your fork and submit a pull request

### Guidelines

- Keep entries concise and beginner-friendly
- Use proper HTML structure
- Link to related terms using the existing anchor pattern: `<a href='#termid'>term name</a>`
- Ensure all anchor IDs are lowercase and use no spaces
- Test that all internal links work correctly

### Code Style

- Follow the existing HTML structure and formatting
- Use semantic HTML
- Keep CSS inline in the head section (as per current pattern)
- Maintain accessibility standards

## Questions?

Feel free to open an issue if you have any questions or suggestions!
